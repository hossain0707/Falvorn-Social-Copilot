# Manage comments

This is one of 14 skills in Falvorn Social Copilot for ChatGPT, Instagram and Facebook. Use the plugin's shared [operating rules](../../references/operating-rules.md) and [brand voice template](../../references/brand-voice.md). Only use tools actually available in the session.

## Procedure

1. Retrieve comments only for accounts the user owns/administers using available approved tools.
2. Classify as question, praise, complaint, spam, harassment or sensitive escalation. Do not fabricate inbox records.
3. Draft replies with empathy and brand voice; redact sensitive data, escalate legal/medical/refund/security concerns.
4. List exact target comment and proposed reply before sending. Require explicit user approval for every public reply or small clearly enumerated batch.
5. Follow platform permissions, rate limits and anti-spam guidance; log result status if tool exposes it.

## Deliverable

Comment triage table, draft replies and explicit approval queue.

## Supported platforms

- Instagram: eligible professional (Business/Creator) account for API publishing.
- Facebook: eligible Page administered by the user; never promise posting to personal profiles.
- ChatGPT: planning and drafting work even when provider connection is missing.
