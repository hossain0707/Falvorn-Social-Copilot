# Repurpose original content

This is one of 14 skills in Falvorn Social Copilot for ChatGPT, Instagram and Facebook. Use the plugin's shared [operating rules](../../references/operating-rules.md) and [brand voice template](../../references/brand-voice.md). Only use tools actually available in the session.

## Procedure

1. Confirm user owns or has rights to reuse the source, or work from their summary and original ideas.
2. Extract useful insights without reproducing copyrighted passages; keep any citations and source links.
3. Create native Facebook Page post, Instagram carousel outline and optional Reel script; rewrite hooks for each audience.
4. Keep all new claims grounded in source, identify missing context and include original CTAs where appropriate.
5. Route chosen final outputs through social-humanize and then social-publishing only on approval.

## Deliverable

Source-to-platform transformation map and ready-to-review platform drafts.

## Supported platforms

- Instagram: eligible professional (Business/Creator) account for API publishing.
- Facebook: eligible Page administered by the user; never promise posting to personal profiles.
- ChatGPT: planning and drafting work even when provider connection is missing.
