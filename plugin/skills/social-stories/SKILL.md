# Stories and sequences

This is one of 14 skills in Falvorn Social Copilot for ChatGPT, Instagram and Facebook. Use the plugin's shared [operating rules](../../references/operating-rules.md) and [brand voice template](../../references/brand-voice.md). Only use tools actually available in the session.

## Procedure

1. Structure a 3-7 frame sequence: opener, context, proof, interaction and CTA.
2. Provide explicit on-screen text and asset direction for every frame; mark polls/stickers that require native manual placement.
3. Adapt sequence to Instagram and Facebook audiences without assuming all sticker features are available by API.
4. Preserve privacy of participants and respect third-party creative rights.
5. Separate STORY SCRIPT from live publishing; check provider support and require approval for each upload.

## Deliverable

Frame-by-frame sequence, interaction cues, platform notes and posting checklist.

## Supported platforms

- Instagram: eligible professional (Business/Creator) account for API publishing.
- Facebook: eligible Page administered by the user; never promise posting to personal profiles.
- ChatGPT: planning and drafting work even when provider connection is missing.
