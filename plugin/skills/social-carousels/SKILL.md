# Carousel and multi-image planning

This is one of 14 skills in Falvorn Social Copilot for ChatGPT, Instagram and Facebook. Use the plugin's shared [operating rules](../../references/operating-rules.md) and [brand voice template](../../references/brand-voice.md). Only use tools actually available in the session.

## Procedure

1. Determine audience problem, number of slides/images, and desired action.
2. Outline first-slide promise, single insight per slide, concrete examples, payoff and save/share CTA.
3. Write complete copy for each card, visual design direction, alt-text options and caption pairs.
4. Do not claim finished graphics exist without actual image files; request or generate visuals only when available and user-authorized.
5. Check account platform format support and asset count via connected tools before attempting upload; route to social-publishing with approval.

## Deliverable

Slides table with copy, design notes, accessibility text, platform captions and export checklist.

## Supported platforms

- Instagram: eligible professional (Business/Creator) account for API publishing.
- Facebook: eligible Page administered by the user; never promise posting to personal profiles.
- ChatGPT: planning and drafting work even when provider connection is missing.
