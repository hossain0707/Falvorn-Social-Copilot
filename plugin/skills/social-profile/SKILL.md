# Profile and Page audit

This is one of 14 skills in Falvorn Social Copilot for ChatGPT, Instagram and Facebook. Use the plugin's shared [operating rules](../../references/operating-rules.md) and [brand voice template](../../references/brand-voice.md). Only use tools actually available in the session.

## Procedure

1. Ask for the handle/Page URL or use an authorized connected account lookup.
2. Evaluate clarity, searchability, audience fit, promise, CTA, links, proof, accessibility and consistency against a documented scorecard.
3. Give before/after text for Instagram name, bio and highlights; separately give Facebook Page description, about section, CTA and pinned post suggestions.
4. Do not claim to update profile/page settings unless a supported tool actually does it; surface manual steps otherwise.
5. Flag missing permissions or unavailable data explicitly.

## Deliverable

Transparent 100-point heuristic, prioritized fixes, revised IG bio and Facebook Page text.

## Supported platforms

- Instagram: eligible professional (Business/Creator) account for API publishing.
- Facebook: eligible Page administered by the user; never promise posting to personal profiles.
- ChatGPT: planning and drafting work even when provider connection is missing.
