# Weekly content calendar

This is one of 14 skills in Falvorn Social Copilot for ChatGPT, Instagram and Facebook. Use the plugin's shared [operating rules](../../references/operating-rules.md) and [brand voice template](../../references/brand-voice.md). Only use tools actually available in the session.

## Procedure

1. Get goal, available assets, resource limits, audience, offers and preferred publishing cadence; use assumptions if missing.
2. Build a calendar with date, audience intent, format, hook, content outline, CTA, owner and status.
3. Distinguish IG-specific Reels/Stories/carousels from FB Page posts/videos/events; avoid identical copy if platform context differs.
4. Propose measurable KPIs per post and a weekly review ritual; do not invent a "best time" without historical insights.
5. Treat everything as DRAFT by default. Pass an approved final post and schedule to social-publishing.

## Deliverable

Seven-day calendar table; asset checklist; measurement and approval plan.

## Supported platforms

- Instagram: eligible professional (Business/Creator) account for API publishing.
- Facebook: eligible Page administered by the user; never promise posting to personal profiles.
- ChatGPT: planning and drafting work even when provider connection is missing.
