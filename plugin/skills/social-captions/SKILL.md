# Captions and post copy

This is one of 14 skills in Falvorn Social Copilot for ChatGPT, Instagram and Facebook. Use the plugin's shared [operating rules](../../references/operating-rules.md) and [brand voice template](../../references/brand-voice.md). Only use tools actually available in the session.

## Procedure

1. Load brand voice, goal, audience, content context, claims and desired CTA.
2. Draft a strong first line, concrete body copy, one primary CTA and optional alternate tone.
3. Make two native versions: Instagram (visual-first, short opening and relevant 3-5 hashtags when appropriate) and Facebook Page (readable context, conversation-friendly wording, no forced hashtags).
4. Confirm factual claims with provided evidence or label them unverified. Do not invent testimonials, discounts, quotes or dates.
5. Run social-humanize before posting. Return drafts only unless user explicitly approves a publish operation.

## Deliverable

Copy-paste Instagram and Facebook drafts, ALT text suggestion where relevant, and claims needing verification.

## Supported platforms

- Instagram: eligible professional (Business/Creator) account for API publishing.
- Facebook: eligible Page administered by the user; never promise posting to personal profiles.
- ChatGPT: planning and drafting work even when provider connection is missing.
