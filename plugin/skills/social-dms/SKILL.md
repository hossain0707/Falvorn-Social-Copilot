# Private messages and lead response

This is one of 14 skills in Falvorn Social Copilot for ChatGPT, Instagram and Facebook. Use the plugin's shared [operating rules](../../references/operating-rules.md) and [brand voice template](../../references/brand-voice.md). Only use tools actually available in the session.

## Procedure

1. Confirm platform and authorized account; access private messages only through approved connection.
2. Draft concise consent-respecting messages that respond to actual inquiries, not unsolicited bulk outreach.
3. Handle personal data minimally; do not reveal sensitive information, impersonate users or promise unsupported actions.
4. Explain channel limits: Facebook Page Messenger may not be supported by the same provider that manages Facebook Page comments; check tool capability, do not assert access.
5. Ask user to approve recipient and exact text for sending, except when a specifically approved bounded automation exists.

## Deliverable

Conversation summary, personalized proposed answer, approval status and channel limits.

## Supported platforms

- Instagram: eligible professional (Business/Creator) account for API publishing.
- Facebook: eligible Page administered by the user; never promise posting to personal profiles.
- ChatGPT: planning and drafting work even when provider connection is missing.
