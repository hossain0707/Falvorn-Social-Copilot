# Analytics and experiments

This is one of 14 skills in Falvorn Social Copilot for ChatGPT, Instagram and Facebook. Use the plugin's shared [operating rules](../../references/operating-rules.md) and [brand voice template](../../references/brand-voice.md). Only use tools actually available in the session.

## Procedure

1. Retrieve authorized dated account metrics through available provider tools or user-supplied exports.
2. Specify period, denominator and formula for engagement; compare platform metrics only where definitions are comparable.
3. Report top/bottom content and why observed patterns might be confounded by format, audience, spend or posting hour.
4. Recommend up to three testable actions with hypotheses, guardrails, and success metrics. Never fabricate statistics or causal claims.
5. Where connected analytics are missing, give a measurement plan and clearly label it as such.

## Deliverable

Metric table with source/time, interpretation, uncertainties, 3 prioritized experiments.

## Supported platforms

- Instagram: eligible professional (Business/Creator) account for API publishing.
- Facebook: eligible Page administered by the user; never promise posting to personal profiles.
- ChatGPT: planning and drafting work even when provider connection is missing.
