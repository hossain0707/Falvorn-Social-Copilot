# Reels and short video

This is one of 14 skills in Falvorn Social Copilot for ChatGPT, Instagram and Facebook. Use the plugin's shared [operating rules](../../references/operating-rules.md) and [brand voice template](../../references/brand-voice.md). Only use tools actually available in the session.

## Procedure

1. Identify objective, topic, audience, platform(s), duration, and footage/asset availability. If unknown, state assumptions briefly.
2. Generate three meaningfully different hooks, each tied to a specific curiosity, tension, or benefit. Explain which one you recommend without claiming virality.
3. Create a timed beat sheet: second ranges, spoken lines, b-roll, on-screen captions, closing CTA, and editing notes.
4. Give platform-specific deliverables: IG hook/caption and FB headline/caption. Cross-post only if the user owns reusable media and has rights to publish.
5. If no finished playable media exists, label the output as a SCRIPT; never say a video has been rendered or published.
6. For account publishing, hand off to social-publishing after the user supplies final video, authorized account and explicit approval.

## Deliverable

Reel concepts table with 3 hooks; one final timed script; IG/FB captions; required footage; approval status.

## Supported platforms

- Instagram: eligible professional (Business/Creator) account for API publishing.
- Facebook: eligible Page administered by the user; never promise posting to personal profiles.
- ChatGPT: planning and drafting work even when provider connection is missing.
