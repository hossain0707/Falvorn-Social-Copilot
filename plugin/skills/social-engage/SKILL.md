# Thoughtful community participation

This is one of 14 skills in Falvorn Social Copilot for ChatGPT, Instagram and Facebook. Use the plugin's shared [operating rules](../../references/operating-rules.md) and [brand voice template](../../references/brand-voice.md). Only use tools actually available in the session.

## Procedure

1. Find topical public conversations only via authorized accessible sources.
2. Draft context-aware, genuinely helpful comments; avoid repetitive templates, unsolicited pitches, mass tagging or engagement bait.
3. Present the account, target post, exact draft and reason for each prospective comment.
4. Require explicit approval per public comment. Use only an authorized tool and confirm the result before reporting success.
5. If commenting on other accounts is not supported by provider/permissions, provide copy-paste suggestions instead of bypassing restrictions.

## Deliverable

Shortlist of relevant posts and individually approved comment drafts; posting confirmation only when verified.

## Supported platforms

- Instagram: eligible professional (Business/Creator) account for API publishing.
- Facebook: eligible Page administered by the user; never promise posting to personal profiles.
- ChatGPT: planning and drafting work even when provider connection is missing.
